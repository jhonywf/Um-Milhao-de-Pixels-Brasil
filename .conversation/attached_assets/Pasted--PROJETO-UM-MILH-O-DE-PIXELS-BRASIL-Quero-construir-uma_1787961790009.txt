# PROJETO: UM MILHÃO DE PIXELS BRASIL 🇧🇷

Quero construir uma aplicação web chamada **Um Milhão de Pixels Brasil**.

Este é um projeto comercial que poderá futuramente receber pagamentos reais. Portanto, desde o início, quero uma arquitetura profissional, organizada, segura e preparada para produção.

## OBJETIVO DO PROJETO

Criar uma parede digital pública formada por exatamente:

**1.000 × 1.000 pixels = 1.000.000 pixels**

A ideia é permitir que pessoas comprem áreas dessa parede e criem suas próprias artes em pixel art.

O preço planejado será:

**R$1,00 por pixel.**

Exemplos:

10 pixels = R$10
100 pixels = R$100
1.000 pixels = R$1.000
10.000 pixels = R$10.000

A compra mínima inicialmente será de:

**10 pixels.**

IMPORTANTE: neste primeiro estágio NÃO implementar pagamentos, Mercado Pago, autenticação ou banco de dados definitivo.

Primeiro quero construir uma fundação sólida e uma experiência visual excelente.
